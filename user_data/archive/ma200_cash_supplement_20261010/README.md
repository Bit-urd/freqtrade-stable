# 原调仓优先的可用现金补仓候选

`ma200_cash_supplement.py`，类 `Ma200CashSupplementStrategy`。基于已保留趋势确认交接版；父类文件原样复制，当前没有部署或替换现有策略。

原调仓先执行，返回的金额或标签原样传回引擎；返回空且目标/交接状态未改变时，才尝试补仓。补仓不写原风险状态，不覆盖父类价格读取，不修改原信号及原调仓函数。追加盈亏仍会改变后续净值和原调仓金额，这种复利路径变化无法消除。

只在上一根完整日线 BTC 与个币趋势合格时补目标金额缺口；用全部可用现金，含充值与卖出所得，按各币缺口比例分配。不强制投满、不为了等权卖出赢家。当天其他原调仓、转档、未成交订单或可能的新开仓让补仓暂缓，保证原逻辑资金优先；因此新增余额并非到账即投入，也不保证固定几天内投入。

每币每日一次额外请求；标记和固定日计划写入交易自定义数据，依赖 Freqtrade 数据库恢复。撤单或部分成交剩余缺口次日重算。低于最小订单暂不下单。原调仓自身的状态更新时间保持原样，本实验不同时修改它。

## 使用

三个策略文件需一起置于独立策略目录，并选择 `Ma200CashSupplementStrategy`。配置 `cash_supplement_enabled: true` 为开启（默认）；设为 `false` 走已保留交接版原行为。账户现金须是分配给该策略的资金；固定 `available_capital` 或 `tradable_balance_ratio` 会继续限制可用投入。dry-run 钱包不自动同步真实充值。
