# CycleRisk 最大回撤归因

范围：2023-01-01～2026-10-06，BTC/SOL/ETH 三币共享1000 USDT，单侧手续费0.1%。逐笔成交重建每币现金和持仓市值，三币权益合计与原生账户曲线一致（误差低于0.000001 USDT）。不把期末强制平仓当作常规策略退出。

## 原因和可验证方向

1. 独立按币复利预算使上涨后的SOL权重升至65.31%。初始等额资金并不等于长期等风险；高波动赢家在反转时主导账户损失。
2. 退出信号较慢，峰值后的持仓回吐很大。2024-10-13开仓的SOL整笔交易仍盈利约890，但从2025-01-18账户峰值至退出已经回吐约1380。只看已平仓交易盈亏会掩盖回撤。
3. 再入场反复受损。SOL峰谷区间新交易21笔亏损、5笔盈利，新入场合计损失约2020。2025-03-03前一日三币均空仓，当天追入后账户损失728.64，其中SOL约547.70。此前SOL只有一天反弹站上EMA20，尚无连续两日确认。
4. 内部风控峰值重置与全历史回撤不同。该区间多数交易日目标风险仍为满仓；BTC恢复允许风险恢复，并不说明账户已经修复历史峰值。此前半峰值记忆改动只改善约1.93个百分点，用户已明确认为不足，未采用。
5. 区间累计费用约224.98，约占净损失5.74%。不是主要损失来源；去掉费用会改变后续资金和交易路径，不能直接当作可实现改善。日度执行项包含买入后当日价格变化，不应误称全部是滑点。

先验证连续两天EMA20入场与对称退出，再验证统一50%单币仓位约束。保留全部失败结果，不因单个避开的亏损交易判断改动有效。所有实验使用已收盘数据、相同六个窗口和持有基准；已经观察过的历史不作为独立样本外证明。
