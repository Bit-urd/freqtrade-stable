# BTC / ETH / SOL：现货与1倍永续六年对比

已完成六次原生策略回测。使用正式BTC两天退出规则，三币等额初始预算、独立已实现利润复投，初始本金10000 USDT，日线做多，逐仓1倍。现货单边手续费0.1%，永续0.05%，滑点0。日终净值使用交易价格，资金费使用结算标记价。

## 主要结果

|窗口|现货收益 / 最大回撤|1倍永续收益 / 最大回撤|永续最终资产相对现货|
|---|---:|---:|---:|
|2020-10-08—2026-10-07|+21676.70% / 61.77%|+4499.39% / 60.06%|少78.88%|
|共同成熟：2021-02-11—2026-10-07|+5430.29% / 62.12%|+4063.36% / 62.43%|少24.72%|

完整六年不能直接视为同一进场机会的比较。SOL现货历史起于2020-08-11，合约起于2020-09-14；MA150首次可以用于下单的日期不同。完整窗口现货SOL首次入场2021-01-08，价格2.3655；永续首次2021-02-11，价格9.1098。共同成熟窗口两者首次SOL下单均为2021-02-12，价格9.2058 / 9.2197。因此共同窗口更适合衡量两种交易工具的差距。

现货完整窗口净利润约93.7%来自SOL，共同窗口约95.8%来自SOL。这是一个高度依赖SOL早期趋势及长期复利的历史组合，收益不能理解为三币普遍具备相同效果。

## 资金费影响

重新运行相同合约价格、手续费和策略，但把资金费设为零；账户风险与仓位也随新的权益重新计算，绝非简单从最终收益加回资金费。

|窗口|实际资金费永续|零资金费永续|实际净资金费|
|---|---:|---:|---:|
|完整六年|+4499.39% / 60.06%|+7410.62% / 59.36%|-98116.39 USDT|
|共同成熟|+4063.36% / 62.43%|+5873.58% / 61.07%|-75300.52 USDT|

共同窗口实际资金费版最终资产416336.43 USDT，零资金费版597358.24 USDT，减少30.30%。长期费用既直接扣钱，也改变后续复投和风险控制路径。零资金费合约高于现货，但本轮手续费不同、交易价格与成交精度不同，不能把剩余差距全部归因于手续费。

费率来自实际历史记录；早期约三年的结算记录缺少标记价，采用相应小时标记价K线开盘价估算：BTC/ETH各3355次、SOL3430次。因此资金费金额存在代理价格误差，不能称全部结算金额均为精确历史实付。

## 持有参照与逐仓清算

|窗口|现货等预算持有收益 / 回撤|永续无追加保证金逐仓持有模型收益 / 回撤|
|---|---:|---:|
|完整六年|+2025.55% / 92.83%|-95.21% / 99.89%|
|共同成熟|+437.23% / 93.45%|-38.42% / 98.86%|

永续持有模型使用完整小时标记价、实际费率、当前缓存维持保证金档位和清算费率，不追加保证金、不自动补保证金、清算后不重新入场。完整窗口模型中ETH于2022-06-18、SOL于2022-11-08、BTC于2022-11-09清算；共同窗口SOL于2022-11-08清算。历史档位及小时内事件排序没有精确复原，因此这是条件化敏感性估算，而非实际历史账户的精确复盘。

长期1倍逐仓也可能因资金费消耗保证金而清算。资金费可从可用余额扣除，不足时从仓位保证金扣除，机制见[Binance官方说明](https://www.binance.com/en/support/faq/detail/360033525031)。不含清算约束的理论永续持有在这两个窗口出现负净值、回撤超过100%，仅保留为账本诊断，不能作为可执行持有收益。

实际策略另作保守资金费压力检查：191400个持仓小时，以累计正资金费且忽略资金费收入及钱包余额计算，最大费用/小时最低标记价比例28.52%，没有越过预留2%维护保证金的98%阈值。这是压力检查，不是历史清算档位的完整复原。
